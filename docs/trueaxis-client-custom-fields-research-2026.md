# Client Custom Fields Research

**Evidence label:** **Research-supported opportunity; not yet an implementation claim.**

Moxie’s official documentation describes extending CRM objects with configurable custom fields, including client fields, and lists multiple types such as text, phone, email, link, numeric, date, and select choices.[1] HoneyBook’s official help center likewise documents adding, editing, deleting, and reordering custom contact fields.[2] These sources support a bounded owner-managed client profile-field capability in TrueAxis HQ.

The evidence justifies a narrow first scope: private, owner-managed client profile fields with a field label, a stable field key, and either text or select values. It does not justify claims of multi-object custom schema, form mapping, merge tokens, automated field propagation, custom data reporting, public/client-editable fields, field-level permissions, complex validation types, or cross-module workflow parity.
